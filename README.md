 Featured Project

 belting

> **A modern product showcase web application**

`belting` is a web application designed to **display and showcase products** with a modern frontend architecture and backend database system.

 Architecture

```text
                    ┌─────────────────────┐
                    │      belting        │
                    │   Product Showcase  │
                    └──────────┬──────────┘
                               │
                 ┌─────────────┴─────────────┐
                 │                           │
          ┌──────▼──────┐             ┌──────▼──────┐
          │   Frontend  │             │   Backend   │
          │             │             │             │
          │ React       │             │ Node.js     │
          │ Vite        │◄───────────►│ Express.js  │
          │ JSX         │             │             │
          │ CSS         │             └──────┬──────┘
          └─────────────┘                    │
                                             │
                                      ┌──────▼──────┐
                                      │    MySQL    │
                                      │   Database  │
                                      └─────────────┘
```

 Technologies

| Layer      | Technology   |
| ---------- | ------------ |
| Frontend   | React        |
| Build Tool | Vite         |
| Routing    | React Router |
| UI         | JSX + CSS    |
| Backend    | Node.js      |
| Server     | Express.js   |
| Database   | MySQL        |

 Project Goal

**belting** focuses on creating a clean and modern product presentation experience while connecting a React frontend with a Node.js backend and MySQL database.

```text
React → API → Express → MySQL
  ↑                    ↓
  └──── Product Data ──┘
```
